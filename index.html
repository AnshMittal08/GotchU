What we can't do

No tool stops every attack. One that says it does isn't being straight with you.

  • The alarm goes off for the fakes. A program that reads your real logins is listed for you to review, but it does not set off the alarm yet.
  • Malware that gets administrator rights can switch off any security tool, this one included.
  • A key you take out of the vault is an ordinary file again until you delete it.
  • It is early. It works on the Windows 11 laptop it was built on, and has not been tested widely.
